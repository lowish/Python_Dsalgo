# Python Data Structures and Algorithms Activities

This repository contains a collection of Python programming exercises, lab activities, and exam tasks focused on Data Structures and Algorithms (DSA). The projects were created as part of school coursework and CodeChums-style activities, covering fundamental concepts in Python programming and algorithm design.

## Overview

This repository includes practical implementations of:

- Arrays and file handling
- Linked lists
- Circular and doubly linked lists
- Stacks and queues
- Recursion
- Sorting algorithms
- Binary trees and binary search trees
- Tree traversal operations

## Course / Activity Coverage

The scripts are grouped by academic period and activity type:

- Prelim: file handling, 1D arrays, 2D arrays, and basic programming tasks
- Midterm: linked list operations and lab activities
- Finals: stacks, queues, recursion, sorting algorithms, and tree structures
- Badging Activity: final and badge-related assessments

## How to Run

Each script is a standalone Python file. You can run it with:

```bash
python "path/to/file.py"
```

Example:

```bash
python "Finals/QuickSorting/QuickSorting.py"
```
